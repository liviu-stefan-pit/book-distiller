# Book Distiller

Code for this project is published at https://github.com/liviu-stefan-pit/book-distiller.

Specs, tickets, prototypes, research notes, handoffs, architecture reports, and change notes are files in this directory. Push to GitHub when asked. Do not open a pull request or file a GitHub issue unless asked.

## Agent skills

Issues and specs live as markdown files under `.scratch/`. See `docs/agents/issue-tracker.md`.

### Triage labels

Default role labels (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
