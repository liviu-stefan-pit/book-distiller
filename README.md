# Book Distiller

Workspace for building an AI reader that distills technical books. The v1 PRD is [`docs/prd.md`](docs/prd.md). Tickets are in [`.scratch/book-distiller/issues/`](.scratch/book-distiller/issues/). Early notes are in [`docs/brainstorming/`](docs/brainstorming/).

Run the launchpad on Windows with `npm install`, then `npm start`. `npm test` rebuilds the app and checks that a text PDF is accepted and a thin one is refused. Work happens in this repo with the agent skills under [`.cursor/skills/`](.cursor/skills/). How those skills find tickets and domain notes is in [`AGENTS.md`](AGENTS.md).
