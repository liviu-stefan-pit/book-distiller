# Book Distiller

Workspace for building an AI reader that distills technical books. Early notes are in [`docs/brainstorming/`](docs/brainstorming/).

There is no application code yet. Work happens in this repo with the agent skills under [`.cursor/skills/`](.cursor/skills/). How those skills find tickets and domain notes is in [`AGENTS.md`](AGENTS.md).
